Данный ТГ-бот создан, чтобы покупатели могли через него ознакомиться и купить самодельные мини-фигурки от блогера Akula_XDD.

Стек: python (telebot, flask), SQLite3.
Вебхуки проходят через Ю-Кассу

Основной файл – polling.py.
Файл config.json содержит информацию о боте.
Файл utils.py содержит отдельные функции для обработки данных.
Файл yookassa_webhook.py содержит вебхук к Ю-Кассе через Flask.
Файлы data.json и data1.json содержат информацию о фигурках и их наличии

Бот на старте приветствует пользователя и предлагает ему выбрать варианты действий: перейти к покупке или ознакомиться с основной информацией о боте.
Если он выбирает "инфо", то выводится поэтапная инструкция как совершить покупку и информация о доставке. 
Если он выбирает "купить", то выводится меню в виде фотографий фигурок, где под каждой фигуркой подпись о наличии товара, количестве и стоимости. А также кнопка для оформления покупки.
При нажатии на эту кнопку пользователю дополнительно показывается инфо о доставке и кнопка с просьбой подтвердить покупку.
При нажатии на эту кнопку бот спрашивает пользователя о его имени, адресе доставки и телефон для связи.
После этого бот перенаправляет пользователя на страницу оплаты.
После успешной оплаты бот отправляет разработчику сообщение о том, кто купил какой товар и данные для доставки.
Также в боте реализовано окно обратной связи с разработчиком через его интерфейс.


На данный момент бот отключён по причине прекращения продаж. Итоговые продажи составили 52000 рублей.
